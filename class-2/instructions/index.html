חלק 1: הוראות לסטודנטים

המשימה

בנו יישום ווב קטן שמקבל תמונה והופך אותה לתמונה חדשה: נקודות, צורות, טקסט, קווים או כל שפה ויזואלית אחרת. היישום צריך לאפשר להעלות תמונה, ולתת כמה פקדים לשליטה בתוצאה.

היישום יכול להיות דף HTML אחד או כמה קבצים, ואפשר להשתמש בכל ספרייה, כולל p5.

דוגמאות אפשר למצוא בגלריה של תרגיל 2.

הגשה

  1. ודאו שיש לכם חשבון GitHub ושמותקן אצלכם Claude Code.
  2. פתחו את Claude Code והעתיקו אליו את כל הפרומפט מחלק 2.
  3. השלימו בפרומפט את שלושת הפרטים המסומנים בצהוב ושלחו.
  4. עקבו אחרי ההנחיות של Claude Code עד שתקבלו קישור ל-pull request. בשלב הזה ההגשה הושלמה.

לאחר שאאשר את ה-pull request, היישום יופיע בגלריה תוך כמה דקות.

הגש בשבילי את היישום שלי לגלריה של תרגיל 2 בקורס. בצע את כל השלבים בעצמך, והסבר לי בקצרה מה אתה עושה.

השם שלי: [שם פרטי ומשפחה]
שם הפרויקט: [שם הפרויקט]
הקוד: [הדביקו כאן את הקוד, או כתבו את הנתיב לקובץ או לתיקייה]

1. הכנה: בדוק ש-git ו-GitHub CLI (gh) מותקנים, ואם חסר משהו התקן אותו. בדוק שאני מחובר ל-GitHub ושמוגדרים ב-git שם ומייל. אם צריך להתחבר, הנחה אותי להריץ gh auth login והמתן עד שאסיים. לעולם אל תבקש ממני סיסמה או טוקן בצ'אט.

2. עותק של הפרויקט: צור fork של omrialloro/p5-gallery בחשבון שלי והורד אותו למחשב. אם כבר יש לי עותק, עדכן אותו מהפרויקט המקורי. צור branch חדש מהגרסה העדכנית של main.

3. הוספת היישום: צור תיקייה חדשה בתוך class-2/apps בשם <שם-פרטי>-<שם-הפרויקט>, באנגלית, באותיות קטנות ועם מקפים. אם השם תפוס, בחר שם דומה. הדף הראשי של היישום חייב להיות קובץ בשם index.html בתוך התיקייה. אם הקוד הוא דף HTML, שמור אותו בשם הזה בלי לשנות אותו. אם הקוד הוא JavaScript בלבד (למשל סקיצת p5), צור סביבו דף index.html מינימלי שטוען אותו. צרף באותה תיקייה את כל הקבצים שהיישום משתמש בהם, וודא שהקישורים אליהם יחסיים. אל תשנה אף קובץ אחר בפרויקט.

4. בדיקה: הפעל שרת מקומי מתיקיית הפרויקט עם python3 -m http.server 8123 (או python ב-Windows) ותן לי קישור ישיר בצורה http://localhost:8123/class-2/#<שם-התיקייה>. עצור וחכה שאאשר שהיישום עובד. אם משהו לא עובד, הסבר לי מה הבעיה, ושנה את הקוד רק אם אאשר.

5. הגשה: אחרי שאאשר, עצור את השרת, עשה commit ו-push ל-fork שלי, ופתח pull request אל הענף main של omrialloro/p5-gallery. ודא שה-pull request כולל רק קבצים מהתיקייה החדשה.

6. סיום: תן לי את הקישור ל-pull request.
